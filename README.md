# Iungere

Iungere is an Ornithe mod that attempts to modernize Minecraft's network and also provides additional client-side optimizations for a smoother, more responsive experience. This is a fork of the [Krypton](https://github.com/astei/krypton) mod by astei.

Iungere is a Latin verb that meaning "to join together, connect, or unite"

# Features
* Fully configurable through the [Argentum](https://github.com/QuicksilverMC/argentum) video settings menu
* Client-side Network Optimizations from [Krypton](https://github.com/astei/krypton)
* Updates Netty to the latest version
* Fixes the unintended hit delay after missed attacks in Minecraft 1.8.9 (toggleable)
* Fixes [MC-67665](https://bugs.mojang.com/browse/MC/issues/MC-67665)
